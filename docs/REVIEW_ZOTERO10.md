## 主线程补充核验

这些不属于前述两位 reviewer 的原始结论：

- Local API 每个受保护响应在使用正文前校验 Zotero-Server-ID；异常写入不跨实例重放。
- Zotero 10 本机实际要求 manifest 的 update_url；只读检查安装包源码并在空 profile 复现后修复。
- 打包的 jar 资源使用 getResourceAsync；getContentsAsync 在 URI 情况返回 XHR，已修复 bootstrap 与设置页并补回归。
- 安装包白名单、固定扩展身份/版本、必要的 locale 目录、敏感文件/符号链接拒绝、可重复构建均有检查。
- 测试夹具在库数据加载前创建条目会卡住 Local API；有/无研究扩展的 A/B 均复现，修正测试启动顺序后两组恢复。
- 测试 Notifier 的中间事件不能提前报告成功，报告写入已排队；失败夹具返回非零退出码。
- 原生桥接等待上限覆盖配置允许的最长 MinerU + 模型处理时间，授权对话框的原超时不变。
- 发布 XPI 在 Zotero 10.0.1 被标记 active；生产请求/高亮控制器经过真实 Gecko 和原生注释 API 验证。

不是“主库已安装、真实模型已完成科研任务”。模型/权重、主库安装与完整界面点击、用户授权后笔记写入的
