# 0.8.9 发布检查

检查日期：2026-09-10。XPI **0.8.9**，油猴脚本 **1.0.19**。本次将此前 0.8.4–0.8.8 本地修补一并提交，并优化 Gemini 后台回传。

## 本次定位与修补

用户反馈：不切回 Gemini 页面时，侧栏往往只收到第一句。失败测试复现：本轮页面停在第一句，后续完整网络正文被 DOM 来源优先级拒绝；完成判断还依赖没有刷新的页面。

- Gemini 的有效响应正文优先于滞后的页面；原始 Markdown / LaTeX 交由侧栏排版。
- 结束帧 + 所有匹配请求/流关闭 + 3.5 秒静默窗口确认完成；新增请求取消计时。没有结束帧、只有思考内容或旧任务的计时器不会完成新问题。
- 完成和回传重试使用独立计时；不切焦点、不模拟额外发送，不改浏览器节能设置。
- 保留页面后备读取、连续对话、图片单次投递、独立请求超时、有限迟到补回、提示词精简及原生公式排版。
