# Zotero AI 0.9.5 / 网页脚本 1.1.5 — 修复 ChatGPT 完成回传与 Gemini 自动发送

修复 ChatGPT 网页已答完、侧栏仍显示未排版文字并持续等待，以及 Gemini 问题留在输入框、需要手动点击发送的问题。

## 修复

- ChatGPT 收到本轮完整网络正文和响应流结束标记后，正文稳定 1.5 秒即可完成回传并触发侧栏排版，无需等待页面用户节点、回答工具栏或停止按钮重绘。
- 区分消息级结束和响应流结束。消息级结束仍须等待传输关闭，响应流结束则允许 HTTP 保持连接；仅取消脚本的克隆读取，不影响网页读取。
- 新请求和任务重置取消旧完成计时器，已失效的旧请求不能结束当前回答；最终网络正文可替换滞留的部分页面正文。
- Gemini 使用编辑器粘贴事务录入完整问题，等待内部文档确认后再发送，避免仅改变页面文字而未真正提交给编辑器。
- Gemini 发送确认限定于本轮用户回合、有效回答或输入区真实状态变化。无关停止按钮、请求、输入框清空和历史节点重建不再单独确认发送；同一用户回合的嵌套节点只计数一次。
- 诊断补充发送点击、确认依据及 ChatGPT 页面读取的等待原因，仅保存状态、数量和时间，不保存问题或回答正文。
