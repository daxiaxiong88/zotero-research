# 0.8.4 候选：图片发送与 ChatGPT 回传修复

状态：本地候选构建，尚未推送或发布新 Release。适用于 Zotero 10.0.x，配套油猴脚本 **1.0.13**。不新增权限、模型配置或数据库写入方式。

## 更新方法

1. 构建或使用本地 `dist/zotero-research-0.8.4.xpi`；Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」，安装后重启。
2. Tampermonkey 中编辑现有连接脚本，用 `userscripts/zotero-research-webai.user.js` 替换全文并保存，确认版本 **1.0.13**。不要同时启用多个副本。
3. 刷新已登录的 ChatGPT / Gemini 页面，确认连接，再从 Zotero 侧栏粘贴图片、输入问题、发送。

必须同时更新 XPI 和脚本。旧插件不支持独立心跳，新脚本会兼容旧协议，但不能获得本版完整的长任务等待保障。

## 修复与借鉴

- 图片：旧版 2.6 秒附件确认窗口会漏掉慢上传，输入框内层容器也可能看不到旁边的附件卡片。现在优先观察完整 composer/form，区分「新附件被接收」和「上传处理完成」。确认接收后不再切换通道重复上传；上传报错时不发送残缺请求。
- 发送：2.5 秒确认过短，网页已接收却仍显示手动发送。改为最长 15 秒确认且只点击一次；输入区域重挂载不等于问题已发送。
- ChatGPT 输入：优先触发编辑器粘贴事务并等待提交，不只修改可见 DOM；整段问题核对，不再以文字长度或相同结尾认定成功。
- ChatGPT 完成：记录本轮新用户消息和回答，网络流用于实时更新，最终与本轮 DOM 对齐。活动 fetch/XHR、停止按钮、busy 状态均阻止提前收尾；隐藏操作栏、代码块的复制按钮、推理消息结束及网络静默都不能单独证明回答完成。
- ChatGPT 公式：从 `data-math-source` / `annotation[encoding="application/x-tex"]` 提取原始公式，保留 Markdown，避免重复拼接 KaTeX 可视/无障碍字形。侧栏支持纯公式 LaTeX 代码块、跨行定界符及其后面的正文。
- 长任务：能力协商后启用独立心跳；同一网页不抢领第二个任务。取消后的旧异步回调不清空新任务；总等待 20 分钟仍未完成则保留部分回答并报错。

```powershell
npm run test:webai:gecko
npm run test:gecko
uv run --isolated --python 3.11 --group dev python -m pytest
uv run --isolated --python 3.11 --group dev ruff check .
uv run --isolated --python 3.11 --group dev mypy src
uv run --isolated --python 3.11 python scripts/build_addon.py
uv run --isolated --python 3.11 python scripts/prepare_zotero_smoke.py --xpi dist/zotero-research-0.8.4.xpi --native-checks --launch
```

浏览器测试会拦截并替换全部网络页面，不使用登录账号。它实际运行侧栏、中继、用户脚本、浏览器 FileList/流及 MathML 渲染器，模拟 2.8 秒后出现附件、3 秒发送确认、4.2 秒流间停顿，断言上传和发送各一次、无手动发送误报、旧轮次不串入、保留末句与公式且窄侧栏不溢出。这是受控浏览器内核集成测试，不是真实 ChatGPT 服务验收。
