# Zotero AI 0.9.1 / 网页脚本 1.1.1

## 本次修复

- 时间轴移到整个 Zotero 插件侧栏的右侧边缘，不再嵌在底部聊天卡片内。跟随侧栏宽度和可见高度，滚动时不移到输入框上方，隐藏侧栏时同时隐藏。
- 接通 Zotero 原生更新源，发布包使用 SHA-256 校验，保留兼容范围和更新说明。
- 接通篡改猴的更新／下载地址；从正式 Release 更新，不拉取未发布的开发脚本。
- 侧栏及网页增加每日更新检查和可关闭的新版提醒，两端均可手动检查。断网不影响聊天，不会误报“最新版”；不修改用户的自动安装设置。

## 安装一次，接入后续更新

旧版没有有效更新地址，**不会自动发现这次修复**。请手动安装以下两个文件一次，重启 Zotero、刷新 AI 网页：

- [XPI 0.9.1](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.9.1/zotero-research-0.9.1.xpi)
- [油猴脚本 1.1.1](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.9.1/zotero-research-webai.user.js)

API 直连用户只需更新 XPI。无需清空设置、文献或对话；不要安装 `.meta.js`，它仅供自动更新检查使用。

之后 Zotero 可在插件管理器检查更新，侧栏也有“检查更新”；油猴菜单有“检查脚本更新”。新版提示提供下载入口，不会强制安装或刷新页面。自动安装和通知时机仍受客户端设置、GitHub 网络连接及浏览器休眠影响。

## 验证边界

发布前验证：283 项 JavaScript、108 项 Python、Chromium／Firefox 各 21 项浏览器场景通过；2 项 Windows 符号链接权限测试跳过。另复测包含“检查更新”入口的侧栏布局，Ruff、脚本组件一致性及发布元数据校验通过。

验证覆盖版本比较、更新链接、检查间隔、断网、提醒去重、输入框焦点保留，以及窄屏位置、侧栏滚动／隐藏、星标、六站时间轴和原有图片／公式回传。浏览器测试采用隔离页面，不等于逐站登录真实账号验证；未擅自修改用户正在运行的 Zotero 或浏览器。完整机制和后续发布步骤见 [更新文档](https://github.com/daxiaxiong88/zotero-research/blob/v0.9.1/docs/UPDATES.md)。
