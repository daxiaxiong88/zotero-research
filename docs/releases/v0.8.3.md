# Zotero AI 科研阅读助手 0.8.3

适用于 **Zotero 10.0.x**；配套油猴脚本 **1.0.12**。本版集中修复侧栏切换、网页回传、API 流处理、MinerU 和回滚打包问题。

## 下载和安装

1. 下载 [zotero-research-0.8.3.xpi](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.8.3/zotero-research-0.8.3.xpi)。在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」中选择它，按提示重启。
2. 使用网页模式时，同时更新 [zotero-research-webai.user.js](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.8.3/zotero-research-webai.user.js) 至 **1.0.12**：在 Tampermonkey 中替换原脚本，不要保留多个副本。
3. Zotero「设置 → 高级」开启“允许此计算机上的其他应用程序与 Zotero 通信”；刷新已登录的 AI 页面，等待连接成功后从侧栏提问。
4. 使用 API 直连时只需安装 XPI，并在插件设置填写接口配置。MinerU 是可选本机依赖，不随 XPI 分发模型权重或 CUDA。

更新会沿用现有设置和对话存档；当前 XPI 采用手动升级，没有可用的自动更新服务。

## 本版修复

- 深度解析中切换文献不再锁死侧栏；旧任务的进度、图片读取和聊天回调不会串到新文献。
- 修复 Zotero 10 当前页读取，识别分屏时实际聚焦的页面。
- 加强 ChatGPT 引用标记清理和响应流追加/替换处理，避免重复、截短或被过时页面内容覆盖。
- 收紧图片投递确认，排除无关页面图片、class 动画和更换输入区域后的旧预览；避免重复点击已进入生成态的按钮。
- 中继自主超时和取消，不再依赖断开的网页继续轮询；发送前检查提供方与连接页面是否一致。
- 改善 OpenAI/Anthropic 接口地址识别、UTF-8/SSE 分块、网关 JSON 响应、取消和错误提示。
- MinerU 缓存迁移读回校验、内存缓存刷新、同附件任务合并、单解析进程限制、扫描件页数处理与停用清理。
- 回滚选择校验真实 XPI 版本和完整性，同版本重复构建不会覆盖有效的上一版。

## 附件说明

- `zotero-research-0.8.3.xpi`：本次安装包。
- `zotero-research-webai.user.js`：网页 AI 连接脚本 1.0.12。
- `USAGE_ZOTERO10.md` / `RELEASE_AUDIT.md`：使用指南与检查报告。
- `*.xpi.manifest.json`：安装包版本及文件清单；`*.xpi.sha256` 与 `SHA256SUMS.txt` 用于校验下载内容。
- `zotero-research-previous-stable.xpi`：**0.8.2 回滚构建**，不是本次最新版；只在需要回退时安装。
- 页面底部的 `Source code (zip/tar.gz)` 是与本次标签对应的完整受版本控制源码，包含完整说明文档和测试。

回滚 XPI 不会自动恢复旧存档备份，请勿自行用旧备份覆盖新对话。

## 验证范围与限制

已执行：177 项 JavaScript 测试、97 项 Python 测试通过；2 项 Windows 符号链接测试因权限限制跳过；Ruff、Mypy、Firefox 窄侧栏 MathML 布局及 Zotero 10.0.1 隔离集成检查通过。XPI 重复构建字节一致。

**本轮没有执行真实登录网页的连续对话/图片端到端验收、实际 GPU 推理或付费模型 API 调用。** 附件确认仍是页面状态启发式判断，不保证每个站点当前版本都能自动发送。网页改版时可能需要更新脚本；出现手动发送提示时请检查实际网页状态。

当前支持个人库中带父文献条目的本地 PDF；群组库、独立 PDF 和未下载附件不在本版支持范围内。详细测试和限制见 [完整检查报告](https://github.com/daxiaxiong88/zotero-research/blob/v0.8.3/docs/RELEASE_AUDIT.md)。
