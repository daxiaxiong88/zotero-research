# Zotero AI 0.9.3 — 在设置页选择浏览器

## 使用

进入 **Zotero 设置 → 科研助手 → 网页 AI 浏览器**，与 API、MinerU 位于同一插件设置页，不占用侧栏。选择后点击“保存浏览器设置”：

- 系统默认：严格跟随系统默认浏览器，不再优先查找 Chrome，也不附加参数。
- Chrome / Edge：自动定位 Windows 常见安装位置；使用已有配置并保留后台优化启动参数。找不到明确选中的浏览器会报错，不擅自替换。
- 自定义路径：填写浏览器可执行文件的绝对路径，不带参数；支持粘贴带外层引号、空格和中文的路径，保存前验证文件。Windows 使用 `.exe`；macOS 使用 `.app` 内的可执行文件。

下次“打开网页”或未连接时首次发送即生效，无需重启 Zotero。浏览器、API、MinerU 配置独立保存；错误路径不覆盖旧设置。

已连接网页不会被强制切换。换浏览器前先在原网页的油猴菜单中断开连接，并在目标浏览器安装配套脚本。插件不结束浏览器进程、不修改系统默认浏览器、不迁移浏览器账号或会话。

未配置时沿用旧行为：Windows 优先 Chrome，未找到时使用系统默认；其他系统默认使用系统浏览器。Chrome / Edge 自动定位目前仅支持 Windows，其他平台使用系统默认或自定义路径。Windows 自定义路径中的 chrome.exe / msedge.exe 同样附加后台参数；若浏览器已在运行，需正常退出其全部窗口后重新启动才应用新参数。

## 验证边界

本次自动化验证：293 项 JavaScript 测试、108 项 Python 测试、48 项 Chromium／Firefox 页面测试通过，合计 449 项。另有 4 项跳过：2 项 Windows 符号链接权限测试，以及 Chromium／Firefox 各 1 项真实页面冻结测试（当前未安装测试专用完整 Chromium；Firefox 不支持该测试使用的 Chromium 生命周期接口）。Ruff、JavaScript 语法、用户脚本构建一致性和发布元数据检查通过。

验证覆盖选择与路径保存、设置页恢复、API／MinerU 隔离、显式默认模式、Chrome／Edge 启动、路径错误、Unicode 参数、关闭插件后禁止启动，以及原有布局和更新提示。测试使用隔离设置页面及原生进程接口替身，不实际启动用户的浏览器或改写其 Zotero 配置。

能用自定义路径启动某个浏览器不代表已完整验证其油猴联动；未宣称 Firefox、Safari 等真实账号环境已逐一验收。浏览器彻底冻结页面时仍无法保证持续回传。
