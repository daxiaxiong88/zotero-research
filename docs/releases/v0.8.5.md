# 0.8.5 候选：图片预览、拖放遮罩与 Gemini 回传

状态：本地候选，未发布。配套用户脚本 **1.0.14**；XPI 和脚本都需更新。

## 本次现场证据

用户截图显示 ChatGPT 仍停在“添加任意内容”的拖放遮罩，侧栏/通知却称截图未进入；Gemini 显示传输超时，同时又错误显示“返回空回答”和“已发送、等待回复”。只读检查确认日常 Zotero 已启用 0.8.4，安装文件 SHA-256 与此前候选一致，不是安装错版本。

浏览器访问工具仍返回 `nodeRepl.fetch request failed`，未取得真实登录页面 DOM。以下是针对截图所示机制构造并复现的代码缺口，不能据此断言真实页面所有问题已消失，尤其 Gemini 此次超时的直接触发原因尚不能从截图确定。

## 修复

- 附件区域：允许包含输入表单的外围 composer 区域，排除聊天历史；识别表单外 CSS 背景缩略图、删除图片控件，不只找表单内的 `img` 或特定 attachment 类名。
- 拖放：`dragenter` 后等待页面挂载遮罩，重新命中实际落点，再投递 `dragover/drop`；无论成功失败都发送结束事件，避免遮罩滞留。收到预览后不再重复投递。
- Firefox 粘贴兼容：原生 `ClipboardEvent` 未保留传入数据时补回同一个 `DataTransfer`，避免图片/文字在事件构造时丢失；输入确认同时完整比对显示文本与原文，避免中文段落换行被 `innerText` 折叠后误报失败。
- Gemini：始终保留本轮模型正文的 DOM 兜底。仅绑定新用户轮次之后的 `model-response`，排除旧回答和用户问题；保留公式源文本，以本轮操作栏、生成状态及活动请求确认完成。
- 心跳：改用已有 Worker 计时机制，减少普通页面计时器被后台节流的影响；这不能阻止浏览器真正冻结或丢弃页面。
- 侧栏：传输失败与空回答分开；完成或失败后结束等待状态，不在未知是否发送时声称已经发送。
- 诊断：油猴菜单新增「联动诊断（复制给开发者）」。只在用户选择时显示版本、结构和投递状态，不自动上传、不新增权限，便于下一步核对真实页面差异。

拖放事件间的等待可参考 [Sync for Zotero 的图片实现](https://github.com/yilewang/sync-for-zotero/blob/938fe1b4d918e6706fa10c286b9121facc8bcedf/extension/content_script.js)；Gemini 用户/模型分区可交叉参考 [网页提取器维护记录](https://github.com/apmantza/GreedySearch-claude/blob/main/CHANGELOG.md)。本次改动在现有实现中完成，没有照搬上述项目代码。

## 更新与验收

1. 安装 `dist/candidates/0.8.5/zotero-research-0.8.5.xpi`，重启 Zotero。
2. 替换油猴现有脚本为 `userscripts/zotero-research-webai.user.js`，确认 **1.0.14**，刷新 AI 网页。
3. 分别在 ChatGPT 和 Gemini 用新的截图问题测试，检查只出现一张预览、自动发送、遮罩退出、侧栏收到完整回答。
4. 若仍失败，保持网页现状，从油猴菜单复制诊断回传，不要反复粘贴相同图片。

本次候选单独输出到子目录，主 `dist/` 的 0.8.3 回滚槽不变。不修改日常库、不重置浏览器、不代替用户安装。
