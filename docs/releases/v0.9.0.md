# Zotero AI 0.9.0 / 网页脚本 1.1.0

新增 Zotero 侧栏与六个网页平台的对话时间轴，方便回看长篇阅读讨论。

## 安装与更新

**请同时更新两个文件**，重启 Zotero 并刷新 AI 网页：

- [Zotero 插件 XPI 0.9.0](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.9.0/zotero-research-0.9.0.xpi)
- [网页连接脚本 1.1.0](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.9.0/zotero-research-webai.user.js)

仍要求 Zotero 10.0.x；API 直连用户只需更新 XPI。油猴中更新原脚本，不要同时运行多个副本。无需清空文献、设置、旧对话或另装时间轴扩展。

## 新功能

- 每轮提问一个节点，悬停预览、点击跳转、当前位置高亮。
- 长按约半秒或键盘按 `S` 标星，刷新和重新打开后恢复。
- Zotero 星标保存在文献对话存档；网页按站点、会话独立保存，两端不跨端同步。
- 支持 ChatGPT、Gemini、DeepSeek、Kimi（含旧域名）、Claude、AI Studio，以及 Zotero 的 API 直连对话。
- 收起／展开、深浅主题和键盘导航；长对话的导航栏可以独立滚动。
- 问题预览不重复显示整段论文材料和知识沉淀历史。
- 回看旧回答时，新消息和流式更新不再重置侧栏滚动位置。

时间轴独立于现有消息传输，不改图片上传、长文本附件或回答完成判定逻辑。

## 验证与边界

发布前验证结果：

- JavaScript：273 项通过。
- Python：104 项通过；2 项符号链接测试因 Windows 创建符号链接权限不足跳过。
- Chromium 和 Firefox：各 20 项通过，共 40 项，覆盖六个平台的节点识别、星标、会话切换、侧栏窄屏布局，以及已有 ChatGPT/Gemini 图片、知识沉淀、后台回传与公式渲染。
- 通过 Ruff、脚本内置组件一致性和语法检查；XPI 内 17 个文件与发布源码逐文件校验一致，回滚槽保留上一版。

浏览器测试使用隔离的代表性网页，未宣称验证了所有真实登录账号。网页时间轴只索引当前已加载消息；懒加载或虚拟化卸载的旧消息需先在网页滚动加载。没有稳定消息 ID 的网站在编辑提问或改变重复消息顺序后可能无法恢复原星标。

交互参考 [Reborn14/chatgpt-conversation-timeline](https://github.com/Reborn14/chatgpt-conversation-timeline)（MIT），由本项目独立实现共享组件并扩展平台。完整说明见仓库中的 [时间轴使用文档](https://github.com/daxiaxiong88/zotero-research/blob/v0.9.0/docs/CONVERSATION_TIMELINE.md)。
