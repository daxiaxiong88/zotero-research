# Zotero AI 0.9.4 / 网页脚本 1.1.3 — 修复 ChatGPT 回答结束与侧栏排版

ChatGPT 网页已经答完时，旧脚本可能继续等待回答工具栏，导致侧栏停留在原始 Markdown、网页徽标一直显示“已发送，等待回答”。本版修复完成判定，使完整回答正常结束等待并触发侧栏排版。

## 修复

- 本轮网络结束信号也可作为完成证据，不再强制依赖旧工具栏按钮。
- 兼容新的回答容器，以及中文“复制回复”等操作按钮；未捕获网络时仍可使用本轮页面读取完成回传。
- 活动请求、响应流、停止按钮和输入区处理状态继续阻止提前完成。正文稳定 1.5 秒后才确认结束，生成中暂停不会截断回答。
- 新请求会清除此前的网络结束标记，避免连续响应沿用旧状态。
