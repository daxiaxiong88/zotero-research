# Zotero AI 科研阅读助手 0.8.9

适用于 **Zotero 10.0.x**，配套网页脚本 **1.0.19**。

## 安装 / 更新

1. 下载 [zotero-research-0.8.9.xpi](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.8.9/zotero-research-0.8.9.xpi)，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」安装，按提示重启。
2. 用 [zotero-research-webai.user.js](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.8.9/zotero-research-webai.user.js) 更新原有 Tampermonkey 脚本至 1.0.19，不要同时保留多个副本。
3. 刷新已经登录的 AI 页面即可；原有网页对话、Zotero 存档和设置不用清空。

## 改进

- **Gemini 后台回传**：网页绘制停在第一句时，改用已经收到的网络正文继续回传；结束判断不必等待页面的停止/复制按钮重新绘制。
- **独立回传重试**：完成计时和失败重试通过独立计时器推进，不抢网页焦点、不再次发送问题。
- **防止过早结束**：网络结束帧、传输全部关闭及静默窗口共同确认完成；思考中、仍在传输或后来启动了新请求都不能提前完成。
- 汇总此前本地修补：图片投递就绪确认、ChatGPT 引用和公式读取、完整 JSON 诊断、心跳与请求独立超时、迟到正文补回、简短提示词及按需发送原文。

网络可读取有效正文时优先使用响应中的 Markdown / LaTeX；否则保留本轮页面后备读取。浏览器真正冻结/丢弃整页时无法保证脚本继续执行；本版不会修改浏览器设置或绕过休眠限制。相关机制见 [Chrome 后台计时说明](https://developer.chrome.com/blog/timer-throttling-in-chrome-88)及[页面生命周期说明](https://developer.chrome.com/docs/web-platform/page-lifecycle-api)。

## 验证与回滚

231 项 JavaScript、97 项 Python 测试通过（2 项符号链接权限测试跳过）；Chromium / Firefox 共 20 项联动测试和 1 项 Firefox MathML 布局检查通过。Zotero 10.0.2 隔离配置加载当前 XPI 通过，未记录插件错误。后台测试包含“页面仍是第一句、普通页面回调停止，但侧栏正文/公式完整”的场景；真实登录账号仍需安装后确认。
