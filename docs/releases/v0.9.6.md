# Zotero AI 0.9.6 / 网页脚本 1.1.6 — 修复 DeepSeek 回传遗漏

修复 DeepSeek 网页回答完整、Zotero 侧栏却缺少段落的问题。此前的缺失来自响应片段解析，不是为节省上下文而主动精简回答。

## 修复

- 按顺序重建全部回答片段，不再只处理首个片段；正确保留空片段声明的正文／思考类型。
- 支持完整响应快照、追加、替换、索引片段和批量更新，包括负索引、相对路径及跨帧沿用的路径与操作。
- 状态、搜索等元数据不再改变正文归属；思考和最终回答分开合并，避免后续答案被误归入思考过程。
- 保留重复的有效文本增量，不以简单去重误删正文；回归覆盖中文、表情、公式、表格和末尾段落。
- README 演示视频改用 GitHub 原生附件嵌入，替代可能被登录态媒体策略拦截的手写 HTML 视频标签；增加直接打开视频的备用入口。

本次运行逻辑改动限定在 DeepSeek 解析器。其他网页的发送、截图上传、完成判定和已有后台回传优化保持不变。
