# 0.8.7 候选：普通聊天轻量化，原文按需发送

本地候选，未发布/推送；配套油猴保持 1.0.17。改动位于 Zotero 侧栏，需要安装新 XPI，不需要重新安装油猴脚本。

## 变化

- 普通问答：只发一行论文标题、当前问题与实际选文/截图；移除每轮重复的长角色规则、问答指引及内部文献标识。
- 无选文时，不再自动检索最多 8 段原文，也不回退追加整段概览。
- 无实际材料时不输出空参考材料区；不再反复声明未附全文 PDF。
- 总结本页、翻译本页、全文总结、填充笔记等显式命令仍按原有预算提供页面或跨页文本；页码、截断说明和实际附件状态保留。它们不再额外重复附上当前选文。
- API 的既有问答历史、前轮原文与知识沉淀记录保留；只改变新一轮自动附加的内容。旧网页消息和本机存档不作追溯修改。

## 可复现的长度比较

同一 SeisLM 标题和 `Explain this.` 问题，用实际侧栏挂载后捕获出站消息，与修改前 HEAD 比较（字符数，不是 token）：

| 场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 无选文，旧适配器返回 8×500 字符摘录 | 4667 | 71 |
| 选文 200 字符 | 831 | 305 |

这些是固定夹具的消息大小，不是模型质量或费用的实测。
