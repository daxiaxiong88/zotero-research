# Zotero AI 0.8.12 / 网页脚本 1.0.22

本次修复 ChatGPT 的长文本附件确认：知识沉淀提示词被网页转换成“已粘贴的文本”附件后，插件不再因为输入框为空而误报失败。

## 安装与更新

- 新用户：[插件 XPI 0.8.12](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.8.12/zotero-research-0.8.12.xpi) + [网页连接脚本 1.0.22](https://github.com/daxiaxiong88/zotero-research/releases/download/v0.8.12/zotero-research-webai.user.js)。要求 Zotero 10.0.x。
- 已安装插件 0.8.11 的用户：**只需在 Tampermonkey 中更新原脚本至 1.0.22，然后刷新 ChatGPT 网页**。XPI 功能未变，0.8.12 仅更新打包版本号，无需为本次修复重装插件。
- 不要同时运行两个连接脚本。设置、文献、侧栏和网页对话不需要清空。
- 若上次失败的文本卡片仍留在网页输入区，先手动发送或移除它，再重试，避免叠加旧草稿。

## 修复内容

- 同时支持编辑器内普通文字和本轮新增的“已粘贴的文本”/ Pasted text 附件。
- 等待附件处理就绪后只发送一次；不重复粘贴，也不截短知识沉淀的问答历史。
- 发送前再次确认仍属于同一任务、同一输入区域；旧附件、历史消息、图片预览和无关草稿不会被误认为本轮文字。
- 正确处理附件上传失败；诊断记录输入方式、字符数和附件数量，不保存提示词正文。
- Gemini、图片发送、API 直连与公式渲染逻辑不变。

## 验证与边界

本次修复通过 256 项 JavaScript 测试、103 项 Python 测试（另有 2 项因 Windows 符号链接权限跳过），以及 Chromium / Firefox 共 8 项知识沉淀和原有图片发送场景。确认完整首尾历史只粘贴一次、只发送一次，完整回答及公式返回侧栏。

浏览器集成使用隔离的受控页面，不代表已在所有真实登录账号中验证；网页改版仍可能影响识别。浏览器完全冻结时脚本依然无法执行，本次不改变后台运行策略。
