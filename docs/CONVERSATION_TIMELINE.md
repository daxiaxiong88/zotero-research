# 对话时间轴

## 使用

同时安装插件 0.9.2 和网页连接脚本 1.1.2 后，重启 Zotero、刷新 AI 网页。不需要额外安装浏览器时间轴扩展。原有设置和阅读记录保留。

- Zotero：圆点导航贴在对话区左侧留白，在可见回答阅读区垂直居中，不在底部对话卡片内，不跨越顶部快捷命令或底部输入框。短对话紧凑排列，长对话在导航内滚动；悬停预览向右展开。随侧栏宽度和阅读区可见高度调整，侧栏隐藏后导航也隐藏。网页模式和 API 直连模式均可用。
- 网页：ChatGPT、Google Gemini、DeepSeek、Kimi（含旧域名）、Claude、Google AI Studio 均支持。网页时间轴不依赖 Zotero 已连接。
- 每个节点代表一次用户提问，点击定位到该提问及其后续回答。当前位置自动高亮。
- 悬停或键盘聚焦预览问题；Zotero 生成的材料包装尽量只显示“本轮问题”，知识沉淀不展开全部历史。
- 长按节点约半秒标星／取消；键盘聚焦后按 `S` 同样可用，上下方向键移动焦点。
- 顶部 `⋮` 收起／展开。网页油猴菜单也有“显示／收起对话时间轴”，各平台分别记忆显示偏好。
- 对话较长时可以在导航栏上滚轮滚动，所有已索引节点都可到达。导航不会修改输入框、发送消息或触发 AI 请求。

## 星标保存

Zotero 星标跟随文献的本机对话 JSON 存档，切换文献、重新打开后恢复。旧存档没有星标字段时视为未标记，无需迁移。清空侧栏记录也会清除其星标。

网页星标存放在 Tampermonkey 存储中，以网站与会话路径隔离，只保存消息标识，不再复制对话正文。网页与侧栏星标**独立保存，不跨端同步**；它们可能有不同的消息数量和上下文，不能按序号直接对应。卸载脚本并清除其数据会丢失网页星标。

## 边界

- 网页导航读取已加载的公共 DOM；不读取 React 私有状态，不调用未公开历史 API，不主动滚动网页抓取全部旧记录。
- 网页若懒加载或虚拟化历史，只有当前已加载的节点可导航；需要先向上滚动加载更早消息。节点变化后时间轴自动重建，已保存的标记仍保留。没有稳定消息 ID 的网站使用内容指纹和同文序号，编辑提问或改变重复消息顺序可能让星标无法重新匹配。
- 插件不会自动把浏览器旧对话导入 Zotero；侧栏索引的是已保存的本机记录。
- 网站改版可能改变消息结构；自动化测试使用隔离的代表性 DOM，并不等于六个真实登录账号均已验证。
- 时间轴不会改变浏览器后台休眠行为，也不参与回答完成状态判定。

## 实现与维护

共享组件为 `addon/content/timeline.js`。网页角色识别在 `userscripts/zotero-research-webai.user.js` 的 `WebTimeline`，与 `Connector` 的发送、抓流、锁及心跳分别管理。Shadow DOM 隔离样式及按钮，避免进入网页的输入／附件选择器。DOM 更新节流，滚动高亮按动画帧合并；没有每帧全量重绘或额外后台服务。

修改共享组件后运行 `npm run build:userscript`，再运行 `npm run check:userscript`。发布的油猴文件内置同一份组件，没有远程 `@require` 依赖。
