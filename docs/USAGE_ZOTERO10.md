# Zotero 10 使用指南（v0.7.5）

核心体验只有一件事：在 Zotero 看 PDF 时，从右侧栏把问题发送到当前浏览器网页里的 AI，回答流式自动带回 Zotero，页码来源可以点击跳回 PDF。

网页模式直接通过 Zotero 自带的本机端口（23119）与油猴脚本通信，没有 Python 后台进程，无需 API key 或配对令牌。API 直连模式使用插件设置中填写的模型配置。

## 1. 安装

### 安装 XPI

1. 关闭正在运行的旧版 Zotero Research（如果有），并重启 Zotero。
2. 打开 Zotero 10，选择“工具 → 插件”。
3. 点击右上角齿轮，选择“从文件安装插件”。
4. 选择项目目录中的 `dist/zotero-research-0.7.5.xpi`。
5. 确认 Zotero「设置 → 高级」中已勾选“允许此计算机上的其他应用程序与 Zotero 通信”（这是本机端点的总闸）。

从 0.5.1 更新时只需安装新 XPI，不需要更改 API 配置；油猴脚本建议更新到 README 标注的最新版本。

### 安装油猴脚本

1. 在 Chrome 或 Edge 安装并启用 Tampermonkey。
2. 打开 `userscripts/zotero-research-webai.user.js`，复制全部内容。
3. 在 Tampermonkey 新建脚本，粘贴并保存；如果已有本脚本，编辑原脚本并替换全文，避免同时运行多个副本。确认版本为 **1.0.8**，更新后刷新 AI 网页。
4. 打开以下任一网页 AI 并登录：
   - `https://gemini.google.com/`
   - `https://chat.deepseek.com/`
   - `https://chatgpt.com/`
   - `https://www.kimi.com/`（或 kimi.moonshot.cn）
   - `https://claude.ai/`
   - `https://aistudio.google.com/`

## 2. 连接

脚本在页面加载后自动连接 Zotero；也可以通过脚本菜单“🔗 连接 Zotero”手动连接。连接成功后：

- 网页右下角出现徽标：“Zotero：已连接，等待 Zotero 消息”。
- Zotero 侧栏顶部显示“Gemini 已连接”（或对应的站点名）。

注意：

- 同一浏览器只允许一个标签页持有连接；其他标签页会提示“另一标签页已连接”。
- 断开或重连由脚本菜单管理；页面被新标签页接管后，旧页面会停止轮询。侧栏“打开网页”明确让新页接管连接；要继续已有对话，请在已有对话页使用脚本菜单“连接 Zotero”。

## 3. 发送第一条消息

打开论文后，右侧栏从上到下包括：论文标题与连接状态、快捷命令芯片、当前选文、网页 AI 对话、输入框。

- 直接点击快捷命令，或在输入框输入问题后按 Enter（Shift+Enter 换行）。
- 发送时侧栏按任务取材：本页命令取当前页；全文总结和填充笔记取完整提取文本或跨页概览；普通提问检索相关片段，并带上当前选文。提示词会标明实际提供的材料范围和物理页码。
- 油猴脚本从 Zotero 长轮询取到任务后，自动填入网页 AI 输入框并点击发送。
- 回答从网页 AI 自己的 API 流中捕获（不是猜 DOM），逐段流式回传到侧栏。
- 继续追问即可沿用网页 AI 侧的对话上下文。API 直连则自动携带之前的完整问答对及提供过的原文。点击“清空”会清除当前文献的侧栏记录和本机存档，不会删除浏览器网页中的对话。

## 4. 快捷命令

| 命令 | 用途 |
| --- | --- |
| 总结本页 | 概括当前阅读内容和关键数据 |
| 翻译本页 | 按原文顺序逐段完整翻译当前页，保留术语、数字、单位、公式及编号 |
| 部分总结 | 总结 PDF 中已经选中的文字 |
| 全文总结 | 按研究缺口、方法假设、结果、证据强度和局限给出概览；只提供摘录时会标明范围 |
| 填充笔记 | 整理成可以粘贴到 Zotero 笔记的 Markdown |
| 上传材料 | （仅网页模式）提示你在网页 AI 页面上传附件/截图/笔记并保持对话上下文 |
| 知识沉淀 | 合并同类问题，保留后续纠正，区分有依据的解答与待核实问题，可复制或写入子笔记 |

API 直连模式可用「附带全文 PDF」勾选框把整篇论文原文发给模型；「上传材料」仅在网页中继模式显示（浏览器文件选择必须由人完成）。

无需配置额外提示词。想改变回答方式，直接在问题里指定即可，例如“用适合初学者的方式，逐步解释公式 3 中的每个变量和假设”“只翻译，不解释”或“请用 5 句话回答”。

全文总结的文字材料预算为 60,000 字符（不是 token）：短论文提供所有提取文本；长论文从首、中、尾等最多 16 页均匀取样，不能等同于阅读全文。文字提取无法替代原始图像；需要细读图表或覆盖整篇长论文时，在网页中上传 PDF，或在支持附件的 API 模式勾选「附带全文 PDF」。详细规则见 [提示词设计说明](PROMPT_DESIGN.md)。

## 5. 选文和页码

在 Zotero PDF 阅读器中选中文字后，点击选区旁的“发送到科研助手”。侧栏显示选文和物理页码，点击页码跳回对应 PDF 页面。

“部分总结”或普通提问时，当前选文会自动附在本轮消息中；每条回答下方还会列出本轮提供的证据页码，点击即可跳转。切换到另一篇文献后，侧栏显示该文献自己的对话存档，没有记录时为空，避免两篇论文混在一起。

## 6. 安全边界

- 网页 AI 属于云端处理：问题、选文和证据片段会进入所选网页 AI；发送即出网，由你决定发到哪个站点。
- 端点仅监听本机（127.0.0.1:23119），拒绝 HTTP(S) 网页 Origin 的直接请求，允许油猴扩展请求；Zotero 的“允许其他应用通信”开关即总闸。
- 插件不直接访问 zotero.sqlite；只有点击「知识沉淀」结果的「写入子笔记」才会创建子笔记。MCP 工具只读。
- 中继任务和连接令牌保存在内存；阅读对话另存于本机，用于重开文献后恢复。

## 7. MCP（可选，供 Codex）

`zotero-research-mcp` 提供 8 个只读工具：search_items、get_item_context、extract_pdf、retrieve_evidence、generate_reading_card、analyze_paper、locate_quote、health_check。无模型配置时 analyze 返回带页码的证据摘录，由 Codex 自己完成推理。安装：`uv pip install -e .`，命令 `zotero-research-mcp`（stdio 传输）。

## 8. 常见问题

### 知识沉淀提示“单轮对话过长”

插件会先缩减历史参考原文，尽量保留完整的问题与回答；只有完整问答仍无法放入本轮预算时才停止发送。原始记录没有被删除或截断，也不会自动拆成多次收费的模型调用。可以先就较短范围做总结，或把需要整理的部分复制后分段提问；若只是较早问答被省略，结果旁会显示实际覆盖范围。

### 重开文献时输入框暂时不可用

正在恢复该文献的本机存档，完成后会自动恢复输入，避免新问答覆盖尚未加载的旧记录。磁盘保存或清空失败会显示明确错误，不代表网页模型调用失败。

### 存档里的 `.pre-v2.bak` 是什么

这是 0.7.5 首次精简旧存档前保留的迁移备份，后续正常保存不会覆盖它。清空当前文献记录时会同时清掉本项备份；没有自动清理其他文献的动作。旧版安装包由构建脚本自动保存为 `dist/zotero-research-previous-stable.xpi`（连同校验值），通常回退 XPI 即可，不要随手用旧备份覆盖包含新问答的当前存档。详见 [存档与回滚说明](STORAGE_AND_BUDGET.md)。

### 侧栏没有内容

确认安装 0.7.5 XPI；在条目或阅读器中重新点开“科研助手”侧栏。仍为空时停用插件、重启、重装最新 XPI。

### 侧栏显示“等待网页连接”

确认 Tampermonkey 脚本已启用、当前页面在支持列表内、Zotero 在运行且已勾选“允许其他应用通信”。必要时用脚本菜单“🔗 连接 Zotero”手动连接；连接失败的提示会说明原因。

如果你更新了 XPI 但网页仍显示“连接失败”，检查油猴脚本版本是否与 README 一致。1.0.0 没有发送 Zotero 10 必需的连接协议请求头，不能只靠更新 XPI 修复。

### 浏览器没有自动发送

先清空网页 AI 的输入框并刷新页面。网页改版导致输入框或发送按钮选择器变化时，更新脚本中 `SITES` 对应站点配置；30 秒内找不到按钮时脚本会转为“等待你手动发送”，手动发送后回答仍会回传。

### 回答没有回到 Zotero

保持 Zotero 与网页都打开。脚本徽标会显示当前状态；握手失败后每 5 秒重试。主动断开或切换页面会将已领取的任务标记为失败，需要手动重新发送，不会自动重复提问。尚未领取的排队任务保留。

### “上传附件”没有自动选择文件

这是预期行为。文件选择必须由你在网页 AI 页面完成；上传完成后直接继续提问，网页侧对话上下文仍在。

### 想换一个网页 AI

侧栏“打开网页”按钮按当前选择的提供方打开对应站点；也可以自己在浏览器打开任意支持列表中的站点。
