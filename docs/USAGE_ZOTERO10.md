# Zotero 10 使用指南（v0.8.10）

配套网页脚本 1.0.19。本次需同时升级 XPI 与油猴脚本，Gemini 优先从响应流回传，减少对后台页面重新绘制的依赖。包含此前的请求独立超时、迟到正文补回、提示词精简和按需取材。

核心体验只有一件事：在 Zotero 看 PDF 时，从右侧栏把问题发送到当前浏览器网页里的 AI，回答流式自动带回 Zotero，页码来源可以点击跳回 PDF。

网页模式直接通过 Zotero 自带的本机端口（23119）与油猴脚本通信，没有 Python 后台进程，无需 API key 或配对令牌。API 直连模式使用插件设置中填写的模型配置。

## 1. 安装

### 安装 XPI

1. 关闭正在运行的旧版 Zotero Research（如果有），并重启 Zotero。
2. 打开 Zotero 10，选择“工具 → 插件”。
3. 点击右上角齿轮，选择“从文件安装插件”。
4. 选择从 Releases 下载的 `zotero-research-0.8.10.xpi`（自行构建时为 `dist/zotero-research-0.8.10.xpi`）。
5. 确认 Zotero「设置 → 高级」中已勾选“允许此计算机上的其他应用程序与 Zotero 通信”（这是本机端点的总闸）。

升级时手动安装新 XPI，不需要更改 API 配置；当前没有自动更新服务。油猴脚本也应更新到 README 标注的最新版本。

### 安装油猴脚本

1. 在 Chrome 或 Edge 安装并启用 Tampermonkey。
2. 打开 `userscripts/zotero-research-webai.user.js`，复制全部内容。
3. 在 Tampermonkey 新建脚本，粘贴并保存；如果已有本脚本，编辑原脚本并替换全文，避免同时运行多个副本。确认版本为 **1.0.19**，更新后刷新 AI 网页，不必清空原有网页对话。
4. 打开以下任一网页 AI 并登录：
   - `https://gemini.google.com/`
   - `https://chat.deepseek.com/`
   - `https://chatgpt.com/`
   - `https://www.kimi.com/`（或 kimi.moonshot.cn）
   - `https://claude.ai/`
   - `https://aistudio.google.com/`

## 2. 连接

脚本在页面加载后自动连接 Zotero；也可以通过脚本菜单“🔗 连接 Zotero”手动连接。连接成功后：

- 网页右下角出现徽标：“Zotero：已连接，等待 Zotero 消息”。
- Zotero 侧栏顶部显示“Gemini 已连接”（或对应的站点名）。

注意：

- 同一浏览器只允许一个标签页持有连接；其他标签页会提示“另一标签页已连接”。
- 断开或重连由脚本菜单管理；页面被新标签页接管后，旧页面会停止轮询。侧栏“打开网页”明确让新页接管连接；要继续已有对话，请在已有对话页使用脚本菜单“连接 Zotero”。

## 3. 发送第一条消息

打开论文后，右侧栏从上到下包括：论文标题与连接状态、快捷命令芯片、当前选文、AI 对话、输入框。

- 直接点击快捷命令，或在输入框输入问题后按 Enter（Shift+Enter 换行）。
- 普通提问只带简短论文标题、问题和当前选文/截图；没有选文时不自动检索 PDF，也不追加概览，不再重复大段角色规则、内部文献标识或“未附全文”等说明。
- 需要新的论文原文时，点击本页、全文总结或填充笔记等命令，或主动上传 PDF。显式阅读命令仍按实际范围提供原文、页码及必要的截断说明；本页/全文命令不再额外重复附上当前选文。网页里已经发送过的旧消息不会被修改，精简从新消息开始生效。
- 油猴脚本从 Zotero 长轮询取到任务后，自动填入网页 AI 输入框并点击发送。
- 回答优先从网页 AI 的响应流中捕获；部分站点也会使用回答区域的 DOM 作为补充。网页改版可能影响提取，需要更新脚本。
- 继续追问即可沿用网页 AI 侧的对话上下文。API 直连则自动携带之前的完整问答对及提供过的原文。点击“清空”会清除当前文献的侧栏记录和本机存档，不会删除浏览器网页中的对话。

## 4. 快捷命令

| 命令 | 用途 |
| --- | --- |
| 总结本页 | 概括当前阅读内容和关键数据 |
| 翻译本页 | 按原文顺序逐段完整翻译当前页，保留术语、数字、单位、公式及编号 |
| 部分总结 | 总结 PDF 中已经选中的文字 |
| 全文总结 | 按研究缺口、方法假设、结果、证据强度和局限给出概览；只提供摘录时会标明范围 |
| 填充笔记 | 整理成可以粘贴到 Zotero 笔记的 Markdown |
| 上传材料 | （仅网页模式）提示你在网页 AI 页面上传附件/截图/笔记并保持对话上下文 |
| 知识沉淀 | 合并同类问题，保留后续纠正，区分有依据的解答与待核实问题，可复制或写入子笔记 |
| 深度解析 | 手动调用本机 MinerU 重新提取全文、公式和表格；之后本页/全文等取材命令优先使用缓存，不向普通聊天自动灌入全文 |

API 直连模式可用「附带全文 PDF」勾选框把整篇论文原文发给模型；「上传材料」仅在网页中继模式显示（浏览器文件选择必须由人完成）。

无需配置额外提示词。想改变回答方式，直接在问题里指定即可，例如“用适合初学者的方式，逐步解释公式 3 中的每个变量和假设”“只翻译，不解释”或“请用 5 句话回答”。

全文总结的文字材料预算为 60,000 字符（不是 token）：短论文提供所有提取文本；长论文从首、中、尾等最多 16 页均匀取样，不能等同于阅读全文。文字提取无法替代原始图像；需要细读图表或覆盖整篇长论文时，在网页中上传 PDF，或在支持附件的 API 模式勾选「附带全文 PDF」。详细规则见 [提示词设计说明](PROMPT_DESIGN.md)。

## 5. 选文和页码

在 Zotero PDF 阅读器中选中文字后，点击选区旁的“发送到科研助手”。侧栏显示选文和物理页码，点击页码跳回对应 PDF 页面。

“部分总结”或普通提问时，当前选文会自动附在本轮消息中；选文卡片上的页码可以点击跳转。回答正文可能含页码说明，但不是每个 AI 生成的页码都支持点击。切换到另一篇文献后，侧栏显示该文献自己的对话存档，没有记录时为空。

当前支持个人库中带父文献条目的本地 PDF；群组库、独立 PDF 条目和未下载的附件不在本版支持范围内。切换文献或清空侧栏会撤销本机等待中的聊天任务；网页已经发送的消息不会被远程撤回。深度解析在后台继续保存当前任务的结果，侧栏不会因此锁住另一篇文献。

## 6. MinerU 深度解析（可选）

在插件设置中填写 `mineru.exe` 和完整的本地 VLM 权重目录，保存后打开一篇 PDF，点击侧栏「深度解析」。首次启动会加载模型；耗时取决于页数、版面和显卡，模型加载阶段并不等于卡死。

0.7.7 已修复成功进程被误判为 `MinerU 退出码 [object Object]` 的问题。解析前会在独立运行目录中创建一个内容不变的短文件名临时副本，避免论文长标题让 MinerU 内部图片路径超过 Windows 的 260 字符限制；任务结束后自动清理，Zotero 原附件不会改名。复杂论文只在连续 15 分钟没有任何输出时终止，同时保留 60 分钟总上限；正常输出进度的长任务不会在第 15 分钟被强制终止。若 MinerU 真正非零退出，侧栏会优先显示任务 JSON 中的底层错误，例如 `CUDA out of memory`、缺少模块或权重错误。遇到显存不足时，先关闭占用显卡的程序再重试；解析结果只有成功后才写入当前附件的本机缓存。

从 0.7.9 起，MinerU 缓存和临时运行目录位于 Zotero 数据目录的 `zotero-research-mineru/` 子目录，而不是系统盘上的 Zotero 配置目录。本机当前数据目录若为 `D:\Zotero\paper`，对应路径就是 `D:\Zotero\paper\zotero-research-mineru`。插件会按需读取旧位置中的有效缓存：只有新位置写入成功后才删除旧文件，迁移失败时仍可继续使用旧缓存。

0.8.3 起，同一个附件的重复解析请求会合并；同一插件实例同时只运行一个解析任务，其他文献会提示已有任务占用。切换文献不会取消后台解析，另一篇仍能正常聊天；停用插件时会尝试终止解析进程并清理临时目录。缓存命中后会同步刷新内存中的 PDF 文本，不需要重启才能使用新解析结果。

## 7. 安全边界

- 网页 AI 属于云端处理：问题、选文和证据片段会进入所选网页 AI；发送即出网，由你决定发到哪个站点。
- 端点仅监听本机（127.0.0.1:23119），拒绝 HTTP(S) 网页 Origin 的直接请求，允许油猴扩展请求；Zotero 的“允许其他应用通信”开关即总闸。
- 插件不直接访问 zotero.sqlite；只有点击「知识沉淀」结果的「写入子笔记」才会创建子笔记。MCP 工具只读。
- 中继任务和连接令牌保存在内存；阅读对话另存于本机，用于重开文献后恢复。

## 8. MCP（可选，供 Codex）

`zotero-research-mcp` 提供 8 个只读工具：search_items、get_item_context、extract_pdf、retrieve_evidence、generate_reading_card、analyze_paper、locate_quote、health_check。无模型配置时 analyze 返回带页码的证据摘录，由 Codex 自己完成推理。安装：`uv pip install -e .`，命令 `zotero-research-mcp`（stdio 传输）。

## 9. 常见问题

### 知识沉淀提示“单轮对话过长”

插件会先缩减历史参考原文，尽量保留完整的问题与回答；只有完整问答仍无法放入本轮预算时才停止发送。原始记录没有被删除或截断，也不会自动拆成多次收费的模型调用。可以先就较短范围做总结，或把需要整理的部分复制后分段提问；若只是较早问答被省略，结果旁会显示实际覆盖范围。

### 重开文献时输入框暂时不可用

正在恢复该文献的本机存档，完成后会自动恢复输入，避免新问答覆盖尚未加载的旧记录。磁盘保存或清空失败会显示明确错误，不代表网页模型调用失败。

### 存档里的 `.pre-v2.bak` 是什么

这是 0.7.5 首次精简旧存档前保留的迁移备份，后续正常保存不会覆盖它。清空当前文献记录时会同时清掉本项备份；没有自动清理其他文献的动作。旧版安装包由构建脚本自动保存为 `dist/zotero-research-previous-stable.xpi`（连同校验值），通常回退 XPI 即可，不要随手用旧备份覆盖包含新问答的当前存档。

### 公式显示为 LaTeX 原文

0.8.0 起使用插件内置的 KaTeX MathML 渲染公式，无需联网加载样式或字体，支持 `$...$`、`$$...$$`、`\\(...\\)` 和 `\\[...\\]`。语法不完整的公式会安全地保留原文。

0.8.1 起，长块级公式只在公式自身区域内横向滚动，不再撑宽 Zotero 侧栏；正文会继续随侧栏宽度自动换行。

0.8.2 起，ChatGPT 的内部 `filecite` 引用标记会在进入侧栏和恢复旧存档时自动清理。

0.8.4 起，ChatGPT 网页回传优先提取公式的原始 LaTeX，避免把网页的重复数学字形拼成正文；标记为 `latex`、`tex`、`math` 的纯公式代码块也会尝试渲染。完整 LaTeX 文档、普通程序代码和未闭合公式继续保留原文。旧存档如果已经丢失后半段或公式原始结构，需要重新提问，更新不会凭空补回缺失内容。

### 侧栏没有内容

确认安装最新 XPI（当前版本为 0.8.10）；在条目或阅读器中重新点开“科研助手”侧栏。仍为空时停用插件、重启、重装最新 XPI。

### 侧栏显示“等待网页连接”

确认 Tampermonkey 脚本已启用、当前页面在支持列表内、Zotero 在运行且已勾选“允许其他应用通信”。必要时用脚本菜单“🔗 连接 Zotero”手动连接；连接失败的提示会说明原因。

如果你更新了 XPI 但网页仍显示“连接失败”，检查油猴脚本版本是否与 README 一致。1.0.0 没有发送 Zotero 10 必需的连接协议请求头，不能只靠更新 XPI 修复。

### 浏览器没有自动发送

先清空网页 AI 的输入框并刷新页面。网页改版导致输入框或发送按钮选择器变化时，更新脚本中 `SITES` 对应站点配置；30 秒内找不到按钮时脚本会转为“等待你手动发送”，手动发送后回答仍会回传。

截图先确认网页出现新的附件，再等待上传完成；等待上传不是粘贴失败。已接收的图片不会因为还在处理而再次粘贴。点击发送后最多等待 15 秒确认，期间不会再次点击可能已经变成“停止”的按钮。若网页明确报告上传错误，侧栏会显示错误，不会仅把文字发送出去。

0.8.5 / 脚本 1.0.14 扩展到内层表单外的缩略图和 CSS 背景图，并等待拖放遮罩挂载后向实际落点投递、清理遮罩。若提示未确认图片但网页已有预览，请直接发送，不要重复粘贴。

若仍失败，在 **AI 网页的 Tampermonkey 菜单 →「联动诊断（复制给开发者）」→「下载 JSON」** 保存完整报告并发送文件。1.0.16 改用完整文本框与 JSON 下载，避开 Chrome 原生 prompt 对长文本的 2000 字符中间截断。1.0.17 在点击复制或下载时重新采样，并增加 `runtime` 与 `recentRuntimes`：同一标签页最多保留 4 个脚本实例、每实例最近 20 个事件，总存储上限 48000 字符。任务编号、领取状态、心跳、读取字符数与回传结果可以跨页面重载核对；不恢复或自动重发旧任务。报告不保存问题正文、回答正文、图片数据或会话密钥，不自动上传。请仍优先在失败后立即导出；关闭标签页、清理站点存储或存储被浏览器禁用时，不保证历史保留，报告会标明存储是否可用。

### 回答没有回到 Zotero

0.8.10 / 脚本 1.0.19：Gemini 解析到有效网络正文后，优先回传该 Markdown/LaTeX，不让停留在第一句的页面覆盖它。收到结束帧、所有匹配传输关闭且稳定 3.5 秒后完成回传；不能仅凭静默结束，期间新增请求会取消完成计时。没有有效网络正文时仍使用本轮页面读取后备。重试使用独立计时，不自动切焦点、不重复发送问题。

浏览器主动冻结/丢弃整页时，网络回调、页面脚本和 Worker 都可能停止。这种情况下不能保证后台持续运行；恢复后仅按下述范围补回正文，不自动重发问题。普通后台绘制或计时器节流与完整冻结不同；本版回归测试覆盖前者，不声称能绕过后者。

0.8.8 / 脚本 1.0.18：油猴匿名请求会使用 fetch，Chrome 下不能只依赖其原生 `timeout`。脚本改为独立计时并取消超时请求，保留最新正文重试回传，不重复发送问题。Gemini 页面正文保持公式结构，网络结束帧作为另一条完成证据；有活动请求或停止按钮时仍不结束。

如果页面短暂冻结超过 90 秒，侧栏会先释放等待并保留部分正文；同一连接的最新已领取任务在超时后 20 分钟内可补回迟到正文。部分正文补回不会重新锁住输入框，完整答案到达才移除错误提示。取消、断开/切换连接、发起下一问或超出恢复窗口后，不再恢复旧任务；重新加载网页不恢复已丢失的脚本任务状态。

保持 Zotero 与网页都打开。脚本徽标会显示当前状态；握手失败后每 5 秒重试。主动断开或切换页面会将已领取的任务标记为失败，需要手动重新发送，不会自动重复提问。90 秒没有领取任务或没有回传心跳时，本机也会结束等待并提示重试，不依赖断开的网页再次轮询。

0.8.4 / 脚本 1.0.13 支持独立心跳，上传和思考期间不必有正文也能保持等待；心跳不会覆盖已收到的回答。ChatGPT 需要本轮回答的操作栏出现、没有活动请求或停止按钮，并稳定后才确认完成，不再凭 3.5 秒无新文字结束。20 分钟仍不能确认完成时会显示超时并保留部分正文，不将它当作完整回答。

0.8.5 / 脚本 1.0.14 的心跳使用已有 Worker 计时机制，降低后台标签页普通计时器节流的影响；浏览器真正冻结/丢弃标签页仍会中断联动。Gemini 网络抓取缺失时改读本轮 `model-response` 正文，以回答操作栏和生成状态确认完成，不再把 `user-query-content` 当成回答。传输失败不会再同时显示“AI 返回空回答”和“已发送、等待回复”。

脚本 1.0.15 将 XHR 抓取挂到网页自身的构造器，避免只拦截油猴沙箱；Gemini 页面读取同时识别 `user-query` 与 `user-query-content`，嵌套时只算一轮。诊断新增 `lastTask`：即使任务已结束，仍保留发送确认、网络抓取次数、正文长度、页面读取状态和结束原因，不保存正文。1.0.17 起，当前实例的 `lastTask` 与之前实例的 `recentRuntimes` 分开导出：前者为空不再导致历史任务证据一并消失。

0.8.6 修复 Zotero 中继残留等待请求：同页重连或请求重试时，旧浏览器请求已取消，服务端也同步释放其等待位置，避免新任务被交给失效请求，导致侧栏超时但脚本 `lastTask` 为空。已执行任务不重发、不取消。此修复在 XPI 中，油猴 1.0.15 保持不变。

API 直连按连续 120 秒无响应数据、总计 15 分钟两条上限结束等待；正常持续回传的长回答不会在两分钟时中断。服务端报告错误或流意外结束时会显示错误，已经接收的正文会保留，但不应当作完整回答。
