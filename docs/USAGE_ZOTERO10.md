# Zotero 10 使用指南（v0.9.0）

当前正式版为 **0.9.0**，配套网页脚本为 **1.1.0**，要求 **Zotero 10.0.x**。请从 [README 的最新下载表](../README.md#安装) 获取配套文件。**本次需同时更新 XPI 与油猴脚本**，重启 Zotero 并刷新 AI 网页，侧栏和网页才都会出现时间轴。API 直连用户只需更新 XPI。更新说明与验证边界见 [本版发布说明](releases/v0.9.0.md)。

当前版本支持按需启动：在 Windows 上点“打开网页”，或网页尚未连接时首次发送，插件自动通过原生接口请求 Chrome 联动启动，无需额外启动器。已连接时不另开网页；不会自动退出 Chrome。若 Chrome 原本已普通启动，新参数需保存工作、正常退出全部 Chrome 后再从侧栏打开才生效。找不到 Chrome 或使用非 Windows 系统时，通过默认浏览器打开，不附加 Chrome 后台参数。

核心体验只有一件事：在 Zotero 看 PDF 时，从右侧栏把问题发送到当前浏览器网页里的 AI，回答流式自动带回 Zotero，页码来源可以点击跳回 PDF。

网页模式直接通过 Zotero 自带的本机端口（23119）与油猴脚本通信，没有 Python 后台进程，无需 API key 或配对令牌。API 直连模式使用插件设置中填写的模型配置。

## 1. 安装

### 安装 XPI

1. 从上方下载入口获取 `zotero-research-0.9.0.xpi`，不要选择源码压缩包或回滚包。
2. 打开 Zotero 10，选择“工具 → 插件”。
3. 点击右上角齿轮，选择“从文件安装插件”。
4. 选择下载的 XPI（自行构建时为 `dist/zotero-research-0.9.0.xpi`），安装后重启 Zotero。
5. 确认 Zotero「设置 → 高级」中已勾选“允许此计算机上的其他应用程序与 Zotero 通信”。

升级时手动安装新 XPI，不需要更改 API 配置；当前没有自动更新服务。油猴脚本也应更新到 README 标注的最新版本。

### 安装油猴脚本

1. 在 Chrome 或 Edge 安装并启用 Tampermonkey。
2. 下载 README 下载表中的网页连接脚本 `zotero-research-webai.user.js`，在 Tampermonkey 中安装；若浏览器只下载文件，打开该文件并复制全部内容。
3. 若使用复制方式，在 Tampermonkey 新建脚本并粘贴保存；如果已有本脚本，编辑原脚本并替换全文，避免同时运行多个副本。确认版本为 **1.1.0**，更新后刷新 AI 网页，不必清空原有网页对话。
4. 打开以下任一网页 AI 并登录：
   - `https://gemini.google.com/`
   - `https://chat.deepseek.com/`
   - `https://chatgpt.com/`
   - `https://www.kimi.com/`（或 kimi.moonshot.cn）
   - `https://claude.ai/`
   - `https://aistudio.google.com/`

## 2. 连接

脚本在页面加载后自动连接 Zotero；也可以通过脚本菜单“🔗 连接 Zotero”手动连接。连接成功后：

- 网页右下角出现徽标：“Zotero：已连接，等待 Zotero 消息”。
- Zotero 侧栏顶部显示“Gemini 已连接”（或对应的站点名）。

注意：

- 同一浏览器只允许一个标签页持有连接；其他标签页会提示“另一标签页已连接”。
- 断开或重连由脚本菜单管理；页面被新标签页接管后，旧页面会停止轮询。侧栏“打开网页”明确让新页接管连接；要继续已有对话，请在已有对话页使用脚本菜单“连接 Zotero”。

## 3. 发送第一条消息

打开论文后，右侧栏从上到下包括：论文标题与连接状态、快捷命令芯片、当前选文、AI 对话、输入框。

- 直接点击快捷命令，或在输入框输入问题后按 Enter（Shift+Enter 换行）。
- 普通提问只带简短论文标题、问题和当前选文/截图；没有选文时不自动检索 PDF，也不追加概览，不再重复大段角色规则、内部文献标识或“未附全文”等说明。
- 需要新的论文原文时，点击本页、全文总结或填充笔记等命令，或主动上传 PDF。显式阅读命令仍按实际范围提供原文、页码及必要的截断说明；本页/全文命令不再额外重复附上当前选文。网页里已经发送过的旧消息不会被修改，精简从新消息开始生效。
- 油猴脚本从 Zotero 长轮询取到任务后，自动填入网页 AI 输入框并点击发送。
- 回答优先从网页 AI 的响应流中捕获；部分站点也会使用回答区域的 DOM 作为补充。网页改版可能影响提取，需要更新脚本。
- 继续追问即可沿用网页 AI 侧的对话上下文。API 直连则自动携带之前的完整问答对及提供过的原文。点击“清空”会清除当前文献的侧栏记录和本机存档，不会删除浏览器网页中的对话。

### 对话时间轴

侧栏对话区和六个网页平台的右侧都有时间轴：悬停预览问题、点击节点跳回该轮对话、长按约半秒或聚焦节点后按 `S` 标星。可用时间轴上的 `⋮` 按钮收起；网页也可通过油猴菜单切换显示。两端星标独立保存；网页只索引当前已经加载的消息。详情见 [时间轴使用说明](CONVERSATION_TIMELINE.md)。

## 4. 快捷命令

| 命令 | 用途 |
| --- | --- |
| 总结本页 | 概括当前阅读内容和关键数据 |
| 翻译本页 | 按原文顺序逐段完整翻译当前页，保留术语、数字、单位、公式及编号 |
| 部分总结 | 总结 PDF 中已经选中的文字 |
| 全文总结 | 按研究缺口、方法假设、结果、证据强度和局限给出概览；只提供摘录时会标明范围 |
| 填充笔记 | 整理成可以粘贴到 Zotero 笔记的 Markdown |
| 上传材料 | （仅网页模式）提示你在网页 AI 页面上传附件/截图/笔记并保持对话上下文 |
| 知识沉淀 | 合并同类问题，保留后续纠正，区分有依据的解答与待核实问题，可复制或写入子笔记 |
| 深度解析 | 手动调用本机 MinerU 重新提取全文、公式和表格；之后本页/全文等取材命令优先使用缓存，不向普通聊天自动灌入全文 |

API 直连模式的「附带全文 PDF」当前仅支持 Anthropic 兼容协议，所选模型也必须支持 PDF；OpenAI 兼容协议可使用提取文本和粘贴的截图。「上传材料」仅在网页中继模式显示，PDF 文件需在网页中手动选择。

无需配置额外提示词。想改变回答方式，直接在问题里指定即可，例如“用适合初学者的方式，逐步解释公式 3 中的每个变量和假设”“只翻译，不解释”或“请用 5 句话回答”。

全文总结的文字材料预算为 60,000 字符（不是 token）：短论文提供所有提取文本；长论文从首、中、尾等最多 16 页均匀取样，不能等同于阅读全文。文字提取无法替代原始图像；需要细读图表或覆盖整篇长论文时，在网页中上传 PDF，或在支持附件的 API 模式勾选「附带全文 PDF」。详细规则见 [提示词设计说明](PROMPT_DESIGN.md)。

## 5. 选文和页码

在 Zotero PDF 阅读器中选中文字后，点击选区旁的“发送到科研助手”。侧栏显示选文和物理页码，点击页码跳回对应 PDF 页面。

“部分总结”或普通提问时，当前选文会自动附在本轮消息中；选文卡片上的页码可以点击跳转。回答正文可能含页码说明，但不是每个 AI 生成的页码都支持点击。切换到另一篇文献后，侧栏显示该文献自己的对话存档，没有记录时为空。

当前支持个人库中带父文献条目的本地 PDF；群组库、独立 PDF 条目和未下载的附件不在本版支持范围内。切换文献或清空侧栏会撤销本机等待中的聊天任务；网页已经发送的消息不会被远程撤回。深度解析在后台继续保存当前任务的结果，侧栏不会因此锁住另一篇文献。

## 6. MinerU 深度解析（可选）

在插件设置中填写 `mineru.exe` 和完整的本地 VLM 权重目录，保存后打开一篇 PDF，点击侧栏「深度解析」。首次启动会加载模型；耗时取决于页数、版面和显卡，模型加载阶段并不等于卡死。

解析前会在独立运行目录中创建一个内容不变的短文件名临时副本，避免论文长标题让 MinerU 内部图片路径超过 Windows 的 260 字符限制；任务结束后自动清理，Zotero 原附件不会改名。复杂论文只在连续 15 分钟没有任何输出时终止，同时保留 60 分钟总上限；正常输出进度的长任务不会在第 15 分钟被强制终止。若 MinerU 非零退出，侧栏会优先显示任务 JSON 中的底层错误，例如 `CUDA out of memory`、缺少模块或权重错误。遇到显存不足时，先关闭占用显卡的程序再重试；解析结果只有成功后才写入当前附件的本机缓存。

MinerU 缓存和临时运行目录位于 Zotero 数据目录的 `zotero-research-mineru/` 子目录，而不是系统盘上的 Zotero 配置目录。本机当前数据目录若为 `D:\Zotero\paper`，对应路径就是 `D:\Zotero\paper\zotero-research-mineru`。插件会按需读取旧位置中的有效缓存：只有新位置写入成功后才删除旧文件，迁移失败时仍可继续使用旧缓存。

同一个附件的重复解析请求会合并；同一插件实例同时只运行一个解析任务，其他文献会提示已有任务占用。切换文献不会取消后台解析，另一篇仍能正常聊天；停用插件时会尝试终止解析进程并清理临时目录。缓存命中后会同步刷新内存中的 PDF 文本，不需要重启才能使用新解析结果。

## 7. 安全边界

- 网页 AI 属于云端处理：问题、选文和证据片段会进入所选网页 AI；发送即出网，由你决定发到哪个站点。
- 端点仅监听本机（127.0.0.1:23119），拒绝 HTTP(S) 网页 Origin 的直接请求，允许油猴扩展请求；Zotero 的“允许其他应用通信”开关即总闸。
- 插件不直接访问 zotero.sqlite；只有点击「知识沉淀」结果的「写入子笔记」才会创建子笔记。MCP 工具只读。
- 中继任务和连接令牌保存在内存；阅读对话另存于本机，用于重开文献后恢复。

## 8. MCP（可选，供 Codex）

`zotero-research-mcp` 提供 8 个只读工具：search_items、get_item_context、extract_pdf、retrieve_evidence、generate_reading_card、analyze_paper、locate_quote、health_check。无模型配置时 analyze 返回带页码的证据摘录，由 Codex 自己完成推理。安装：`uv pip install -e .`，命令 `zotero-research-mcp`（stdio 传输）。

## 9. 常见问题

### 知识沉淀提示“单轮对话过长”

插件会先缩减历史参考原文，尽量保留完整的问题与回答；只有完整问答仍无法放入本轮预算时才停止发送。原始记录没有被删除或截断，也不会自动拆成多次收费的模型调用。可以先就较短范围做总结，或把需要整理的部分复制后分段提问；若只是较早问答被省略，结果旁会显示实际覆盖范围。

### 重开文献时输入框暂时不可用

正在恢复该文献的本机存档，完成后会自动恢复输入，避免新问答覆盖尚未加载的旧记录。磁盘保存或清空失败会显示明确错误，不代表网页模型调用失败。

### 存档里的 `.pre-v2.bak` 是什么

这是首次精简旧格式存档前保留的迁移备份，后续正常保存不会覆盖它。清空当前文献记录时会同时清掉本项备份；没有自动清理其他文献的动作。源码构建时，构建脚本会将可用的上一版本保存为 `dist/zotero-research-previous-stable.xpi`（连同校验值）；它仅用于回滚，不是最新版。不要随手用旧备份覆盖包含新问答的当前存档。

### 公式显示为 LaTeX 原文

当前插件使用内置的 KaTeX MathML 渲染公式，无需联网加载样式或字体，支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`。语法不完整的公式会安全地保留原文。

长块级公式只在公式自身区域内横向滚动，不会撑宽 Zotero 侧栏；正文会继续随侧栏宽度自动换行。

ChatGPT 的内部 `filecite` 引用标记会在进入侧栏和恢复旧存档时自动清理。

ChatGPT 网页回传优先提取公式的原始 LaTeX，避免把网页的重复数学字形拼成正文；标记为 `latex`、`tex`、`math` 的纯公式代码块也会尝试渲染。完整 LaTeX 文档、普通程序代码和未闭合公式继续保留原文。旧存档如果已经丢失后半段或公式原始结构，需要重新提问，更新不会凭空补回缺失内容。

### 侧栏没有内容

确认安装最新 XPI（当前版本为 0.9.0）；在条目或阅读器中重新点开“科研助手”侧栏。仍为空时停用插件、重启、重装最新 XPI。

### 侧栏显示“等待网页连接”

确认 Tampermonkey 脚本已启用、当前页面在支持列表内、Zotero 在运行且已勾选“允许其他应用通信”。必要时用脚本菜单“🔗 连接 Zotero”手动连接；连接失败的提示会说明原因。

如果你更新了 XPI 但网页仍显示“连接失败”，检查油猴脚本是否为 README 标注的 **1.1.0**，更新后刷新网页；只更新 XPI 不会更新浏览器中的连接脚本。

### 浏览器没有自动发送

ChatGPT 会将部分长文本转成“已粘贴的文本”附件。脚本 **1.1.0** 会认可本轮新增的文本附件，等待其就绪后继续发送，避免将空输入框误判为失败；不会再重复粘贴完整提示词，也不会截短知识沉淀历史。若失败尝试留下的旧文本卡片仍在输入区，先手动发送或移除它，再重试。只更新 XPI 无法修复浏览器中的旧脚本。

先清空网页 AI 的输入框并刷新页面。网页改版导致输入框或发送按钮选择器变化时，更新脚本中 `SITES` 对应站点配置；30 秒内找不到按钮时脚本会转为“等待你手动发送”，手动发送后回答仍会回传。

截图先确认网页出现新的附件，再等待上传完成；等待上传不是粘贴失败。已接收的图片不会因为还在处理而再次粘贴。点击发送后最多等待 15 秒确认，期间不会再次点击可能已经变成“停止”的按钮。若网页明确报告上传错误，侧栏会显示错误，不会仅把文字发送出去。

脚本会检查输入表单周围的缩略图和 CSS 背景图，并等待拖放遮罩挂载后向实际落点投递、清理遮罩。若提示未确认图片但网页已有预览，请直接发送，不要重复粘贴。

若仍失败，在 **AI 网页的 Tampermonkey 菜单 →「联动诊断（复制给开发者）」→「下载 JSON」** 保存完整报告并发送文件。复制或下载时会重新采样，完整 JSON 不受原生弹窗长文本截断影响。报告包含 `runtime`、`recentRuntimes` 和 `lastTask`，可核对任务编号、领取状态、心跳、读取字符数、解析耗时与回传结果；本轮任务时间线独立保留，不会被空闲轮询覆盖。页面重载后可在保留的近期实例中查看历史证据，但不会恢复或自动重发旧任务。报告不保存问题正文、回答正文、图片数据或会话密钥，不自动上传。请在失败后立即导出；关闭标签页、清理站点存储或存储被浏览器禁用时，不保证历史保留。

### 回答没有回到 Zotero

当前配套版本 **0.9.0 / 脚本 1.1.0** 保留了 Gemini 长回答解析优化，并同时捕获 XHR 的 `progress`、`readystatechange` 和 `loadend`。未完成的外层数据帧不再反复重扫，减少大段知识沉淀阻塞心跳、停在第一句的情况；同一批数据只解析一次。

Gemini 以本轮有效响应正文为主要材料，页面读取可补充更完整的内容；不会用停留在第一句的页面覆盖已收到的长答案。收到结束帧、所有匹配传输关闭且稳定 3.5 秒后才确认网络回答完成，不能仅凭静默结束。没有有效网络正文时使用本轮页面读取后备。重试使用独立计时，不自动切焦点、不重复发送问题。

若 Chrome 被 Zotero 完全遮挡时仍卡住，可先保存工作、正常退出全部 Chrome，再通过侧栏“打开网页”启动。插件不会关闭浏览器，也不会改变系统节能设置。浏览器主动冻结或丢弃整页时，网络回调、页面脚本和 Worker 都可能停止；本版可在页面恢复或重新可见时立即采样并续传，但不保证完全冻结期间仍能执行。

如果页面短暂冻结超过 90 秒，侧栏会先释放等待并保留部分正文；同一连接的最新已领取任务在超时后 20 分钟内可补回迟到正文。部分正文补回不会重新锁住输入框，完整答案到达才移除错误提示。取消、断开/切换连接、发起下一问或超出恢复窗口后，不再恢复旧任务；重新加载网页不恢复已丢失的脚本任务状态。

保持 Zotero 与网页都打开。脚本徽标会显示当前状态；握手失败后每 5 秒重试。主动断开或切换页面会将已领取的任务标记为失败，需要手动重新发送，不会自动重复提问。90 秒没有领取任务或没有回传心跳时，本机也会结束等待并提示重试，不依赖断开的网页再次轮询。

脚本提供独立心跳，上传和思考期间不必有正文也能保持等待；心跳不会覆盖已收到的回答。Worker 计时可以减轻普通后台计时器节流，但不能绕过整页冻结。ChatGPT 需要本轮回答的操作栏出现、没有活动请求或停止按钮，并稳定后才确认完成；20 分钟仍不能确认完成时会显示超时并保留部分正文，不将它当作完整回答。

API 直连按连续 120 秒无响应数据、总计 15 分钟两条上限结束等待；正常持续回传的长回答不会在两分钟时中断。服务端报告错误或流意外结束时会显示错误，已经接收的正文会保留，但不应当作完整回答。

### “上传附件”没有自动选择文件

这是预期行为。文件选择必须由你在网页 AI 页面完成；上传完成后直接继续提问，网页侧对话上下文仍在。
