# 提示词与阅读上下文（更新至 0.8.7 候选）

目标：让同一个侧栏在问答、翻译、概览和知识沉淀时做对各自的事，保留连续理解；不新增设置页，不改网页连接协议，不加入 DOI 核验或文献隐私分类。

## 1. 提示词结构

每轮由 `addon/content/panel.js` 统一组装，网页模式与 API 直连共用。普通聊天仅包含：

1. 一行论文标题，用于限定讨论对象；内部 item/attachment 标识不发给模型。
2. 实际选文、截图或用户主动勾选的 PDF 附件（如果有）；没有材料时不创建空的参考材料区，不生成“未附带全文”“没有可用原文”等重复句子。
3. 用户问题，只出现一次。

普通聊天不再附加通用角色与排版规则，也不附加通用问答任务指引。显式快捷命令保留一句简短阅读原则与对应任务指引：例如逐段翻译、结构化概览、知识沉淀。选文保留 PDF 页码及材料起止标识；范围与截断提示只在实际需要时出现。不会自动删除网页中已有的长提示词或聊天记录，也不改变网页会话机制。

## 2. 按任务取材

| 场景 | 送给模型的材料 |
| --- | --- |
| 总结本页 / 翻译本页 | 阅读器当前物理页的全部提取文字，受总预算约束；无法确定当前页时明确说明改用其他页面材料 |
| 普通问答 | 有选文时仅附选文；没有选文时不检索 PDF、不补概览，只沿用当前对话 |
| 图片问答 | 附用户粘贴的图片及问题，可带当前选文；不另外检索 PDF 摘录 |
| 部分总结 | 必须有选文，只附选段 |
| 全文总结 / 填充笔记 | 提取文字总量不超过 60,000 字符时提供全部非空页；更长时最多均匀采样 16 页，包含首尾，过长的单页分别取头尾 |
| API 附带全文 PDF | 普通问答和概览使用实际附件，不重复提取大段全文；本页任务仍提供当前页定位 |
| 上传材料 | 仅确认等待用户上传，不提前宣称已收到附件 |
| 知识沉淀 | 已完成的阅读问答及原文上下文；不再用沉淀指令检索 PDF |

显式阅读任务的材料总预算为 60,000 **字符**，普通聊天的选文最多 12,000 字符。本页/全文任务不再额外附加当前选文。超预算时仍加截断说明，不把长页面默默切成 6,000 字符。提取文本并不代表看到了图表图像；跨页摘录也不代表完整阅读。

本页命令无法读取当前页时，保留既有的检索回退并标明范围。普通聊天不触发这条路径。网页中手动上传的附件是否存在，以网页 AI 实际可见内容为准；需要新原文时应使用本页/全文命令或上传 PDF。MinerU 缓存仍为显式取材命令提供增强文本，不再自动塞入普通追问。

## 3. 连续对话

- 网页模式：依赖当前网页 AI 的原生会话；普通追问只发送本轮任务与材料，不重复粘贴所有历史。
- API 模式：按完整的用户问题与 AI 回答成对携带历史，最后追加一次当前问题及材料，避免旧版的重复本轮问题和孤立 AI 回答。
- 每轮保存最多 24,000 字符的材料上下文，包含原文、材料范围、回退和截断说明，用于后续 API 追问与会话恢复；老存档没有此字段时，从已有证据片段恢复并注明原始任务范围未记录。历史中的 PDF 附件记录不包含文件内容，也不代表本轮重新附带。
- 保存层精简重复的 `evidence`，每段仅保留前 200 字符及定位字段；实际追问依据仍在 `sourceContext`。旧档首次覆盖之前保存迁移备份，正常打开不会改盘。详见 [使用指南中的存档与回滚说明](USAGE_ZOTERO10.md)。
- 普通 API 问答最多带最近 11 轮完整问答；历史与本轮提示词合计采用 150,000 字符预算。超限时先缩减辅助参考材料，仍放不下才移除最早的完整问答；用户问题与回答不在中间截断。
- 知识沉淀允许最多 250 轮完整问答，仍受字符预算限制。API 使用同一文本预算；网页沉淀的最终文本上限为 60,000 字符，计入所有角色标签、分隔符和范围提示。大小预估后再核对实际组装结果。
- 若蒸馏无法纳入任何完整问答，则不调用模型，明确提示单轮过长、需要分段；本地记录保持不变，不自动增加模型调用。只保留部分问答或缩减原文时，范围提示会在消息旁显示，并随存档恢复。
- 旧的沉淀请求和沉淀文档不作为新的阅读问答重复总结。知识沉淀按主题合并问题，保留后续纠正；AI 给出回答不等于用户已经理解或答案已经核实。

以上是字符启发式预算，不是模型 tokenizer 计算，也不保证适配每个模型的上下文窗口。回答本身的长度仍由现有 API 配置和网页模型控制。清空侧栏不会删除网页 AI 自己的历史；换网页新会话也不会自动注入全部侧栏记录。

## 4. 使用示例

无需增加配置，选择任务或直接提问即可：

- 点击「翻译本页」：要求逐段完整翻译，保留数字、单位、公式、引文和图表编号，译注与译文分开。
- “解释公式 3：先说它解决什么问题，再说明变量、单位和推导中的假设。”
- “作者的结论是因果结论还是相关关系？只根据给出的实验设计和结果说明。”
- “刚才说的独立性假设如果不成立，会对这个方法产生什么影响？”
- 阅读后点击「知识沉淀」：保留真正的理解变化和未解决问题，不把所有问答简单串起来。

## 5. 验证与边界

自动化测试直接检查实际出站消息、当前页长文本、全文/跨页取材、截断标记、历史成对裁剪、前轮原文保留、附件去重和知识沉淀上下文，不只检查提示词常量。

这些测试证明消息组装与范围描述按设计工作，不等于真实模型回答质量已经通过 A/B 评测。网页模型的附件读取、超长回答能力和实际回复风格还需要用具体论文验证。提示词改动不要求更新油猴脚本；但 1.0.5 之前的脚本在后台标签页有发送延迟，建议保持最新版本（见 README）。
